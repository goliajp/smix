## 1. Root causes at code level

### Issue #1 — `--activate` crashes at `SmixRunnerUITests.swift:754`

Confirmed. Line 754 is `target.activate()` inside the `resolveApp` closure I introduced in v0.2.1 Phase A2. Closure signature is `@Sendable () -> XCUIApplication` — synchronous, called from async continuations in every app-touching handler. On iOS 26.5 SDK, `XCUIApplication.activate()` is main-actor-isolated; calling from a non-main continuation → `NSInternalInconsistencyException`.

Insight's diagnosis is exact. v0.2.1 correctly identified per-request rebind as the primitive; v0.2.1 implementation put `.activate()` on the wrong thread.

### Issues #2-4 — `takeScreenshot` at `crates/smix-adapter-maestro/src/runtime.rs:1174-1185`

All three surface in the same 12 lines. Current behavior:

```rust
Step::TakeScreenshot { path } => {
    let bytes = self.app.screenshot().await?;
    if let Some(p) = path
        && let Err(e) = std::fs::write(p, &bytes)     // no mkdir, no ext, silent-succeed
    {
        let reason = format!("takeScreenshot write to {p:?} failed: {e}; …");
        warnings.push(reason);                         // ← warning only
    }
    Ok(RunStepReport::Ok)                              // ← runOutcome success anyway
}
```

Three defects sharing one code path: no path prep, no extension convention, no severity tier for load-bearing verbs.

### Issue #5 — notch region diff

Consumer choice (smix captures full sim frame; maestro cropped notch). Documented as re-accept in adoption doc §7.5. No code change.

## 2. Systemic abstraction — 2 gaps

Per `.claude/dogfood/README.md` iron rule, 4 code defects collapse to 2 class-level upgrades:

### Gap A — MainActor-isolation policy

Not: "wrap `activate()` in `MainActor.run`" (point fix).
Yes: "runner has no policy for main-actor-isolated XCUITest calls; every place that touches XCUIApplication needs main-thread audit."

Scope of amplification:
- `XCUIApplication.activate()` (iOS 26.5: main-actor-isolated)
- `XCUIApplication.launch()` (main-actor-isolated when args mutated)
- `XCUIApplication.terminate()` (main-actor-isolated)
- Any future XCUITest API method

Primitive to introduce: `SmixRunnerCore` gets a `dispatchOnMain` central hop. Every main-isolated call routes through it. Comment at the call site names it as "the audit point" for new XCUITest calls.

### Gap B — file-write policy for yaml output verbs

Not: "add mkdir + ext + fail to `Step::TakeScreenshot`" (point fix on that verb).
Yes: "yaml verbs that write to disk have no shared policy layer for (a) path preparation, (b) extension convention, (c) failure severity; each verb rolls its own scattered inline code."

Scope of amplification:
- `Step::TakeScreenshot` (issues #2/#3/#4)
- `Step::StartRecording` (same class — writes MP4 to yaml path)
- `assertScreenshot` recording baseline (auto-record on first run)
- `write_step_debug` in `--debug-output` handler

Primitive to introduce: `crates/smix-adapter-maestro/src/output.rs` — new module with `write_yaml_output(path, bytes, OutputIntent)` helper. All file-writing verbs migrate to it. Comment in module doc names the invariant.

## 3. v0.3.1 landing plan

Semver patch bump (0.3.0 → 0.3.1) — wire format extends only via optional headers/fields; byte-compat with 0.3.0 clients and servers.

### Phase A — MainActor policy (swift)

**A1. `SmixRunnerCore/SmixRunnerServer.swift`** — new central hop helper.
```swift
extension SmixRunnerServer {
    /// v0.3.1 — canonical main-actor hop for XCUITest APIs that
    /// require it (activate / launch / terminate on iOS 26+ SDK).
    /// Every new XCUITest call reviewer categorizes: main-isolated
    /// → route through here; Sendable → direct call.
    static func onMain<T>(_ body: @MainActor () -> T) async -> T {
        await MainActor.run { body() }
    }
}
```

**A2. `SmixRunnerUITests.swift resolveApp` closure** — make async, wrap `.activate()`.
Before:
```swift
let resolveApp: @Sendable () -> XCUIApplication = {
    ...
    if ctx.activate {
        target.activate()   // ← crashes on off-main continuation
    }
    return target
}
```
After:
```swift
let resolveApp: @Sendable () async -> XCUIApplication = {
    ...
    if ctx.activate {
        await SmixRunnerServer.onMain {
            target.activate()
        }
    }
    return target
}
```

**A3. Cascade** — 15 handlers change `let app = resolveApp()` → `let app = await resolveApp()`. Each handler is already `async`, so `await` just adds one keyword.

**A4. Audit other main-isolated call sites**:
- `foregroundHandler` at line 1348 already sync inside main-isolated closure (via `XCUIApplication(bundleIdentifier:).activate()`) — wrap the direct `.activate()` here too
- `LaunchModeResolver` at line 722-724 uses `.launch()` / `.activate()` inside `test_runForever` init — this is on main by virtue of XCTestCase's execution context; leave as-is with `// @MainActor implicit` comment

### Phase B — file-write helper (rust)

**B1. New crate module `crates/smix-adapter-maestro/src/output.rs`**:
```rust
//! v0.3.1 — canonical file-write helper for yaml output verbs.
//!
//! Any new verb that writes to a yaml-specified path MUST go through
//! [`write_yaml_output`], not inline `std::fs::write`. Reviewer
//! invariant: grep for `fs::write` in this crate — every hit
//! should be in this file.

pub enum OutputIntent {
    /// Verb whose whole point is producing this file (takeScreenshot,
    /// startRecording, assertScreenshot baseline record). Write errors
    /// → RunError::Io propagated → runOutcome: failure.
    LoadBearing,
    /// Debug artifact (per-step JSON, fail screenshot). Write errors →
    /// warning only, runOutcome unaffected.
    BestEffort,
}

pub fn write_yaml_output(
    path: &Path,
    bytes: &[u8],
    intent: OutputIntent,
) -> Result<PathBuf, io::Error> {
    let inferred = infer_extension(path, bytes);
    if let Some(parent) = inferred.parent()
        && !parent.as_os_str().is_empty()
    {
        fs::create_dir_all(parent)?;
    }
    fs::write(&inferred, bytes)?;
    Ok(inferred)
}

fn infer_extension(path: &Path, bytes: &[u8]) -> PathBuf {
    if path.extension().is_some() { return path.to_path_buf(); }
    let ext = if bytes.starts_with(b"\x89PNG\r\n\x1a\n") { "png" }
              else if bytes.starts_with(b"\xff\xd8\xff") { "jpg" }
              else { return path.to_path_buf() };
    path.with_extension(ext)
}
```

**B2. Retrofit `Step::TakeScreenshot`**:
```rust
Step::TakeScreenshot { path } => {
    let bytes = self.app.screenshot().await?;
    if let Some(p) = path {
        let written = write_yaml_output(p, &bytes, OutputIntent::LoadBearing)
            .map_err(|e| RunError::Io(format!("takeScreenshot write {p:?}: {e}")))?;
        if written != *p {
            warnings.push(format!("takeScreenshot: auto-appended extension → {written:?}"));
        }
    }
    Ok(RunStepReport::Ok)
}
```

**B3. Retrofit `Step::StartRecording`** — same helper. `LoadBearing` intent.

**B4. Retrofit `write_step_debug`** — `BestEffort` intent (fail-screenshots + per-step JSON).
