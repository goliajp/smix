# dogfood archive

Consumer-correspondence notes from the v0.x–v1.0.x dogfood cycle — shipping
summaries, feedback responses, and version-specific adoption guides written
for and about the in-house consumers (`insight-*`, `gol-611-*`). They drove
many v1.0.x capabilities, and are kept here for that history.

They lived in `docs/ai-guide/` and crowded the durable, AI-facing guides with
dogfood log. The evergreen surface — the numbered guides, `verb-parity`,
`wire-format`, `abi-stability` — stayed there; this correspondence moved here,
the way `docs/plan-history/` holds archived plans.

Kept as written. `hygiene-scan.py` does not sweep this directory (its
version tags and consumer names are the record, not noise), the same
exclusion `docs/plan-history/` carries.

The correspondence files themselves have never been tracked — they name
consumers and cite the consumers' private repos. Moving them here did not
change that; this README is the tracked marker that the directory exists and
why, and whether the notes are ever committed is a separate call.
