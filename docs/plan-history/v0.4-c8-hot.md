### F6. claude -p 性能 + 非确定性预算

- 单次 `claude -p` 实测 round-trip ~3-15s（quota / model 路由 / payload 大小依赖）。C8 3 case = 9-45s。Total acceptance < 5 min 内（plan-cold 风险段未给硬上限；v1.md §4 [3] 5s 是冷启动到首 tap 预算，不约束 acceptance）。
