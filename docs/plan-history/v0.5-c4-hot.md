## 是否含 e2e

**含**——Gate 4/5/6/7 真本机 e2e 路径：
- Gate 4：`bun src/cli/index.ts doctor --json` 真跑 + jq 严格 schema 断言（9-arg Indigo `indigo9 == true` + AXP 5 class 3 selector + claude loggedIn true + runtimes items length >= 1）
- Gate 5：人类（default）模式 6 行 ✓ 全过 + runtimes/claude 加 detail
- Gate 6：`scripts/simx-c4-doctor-smoke.sh` 真跑 + 6 字段 JSON `{all_ok: "ok"}`
- Gate 7：v0.4 acceptance 21 字段 regression gate

理由：C4 涉及真 subprocess (`claude -p ping --tools ""` ~3s + `xcrun simctl list runtimes` ~100ms + `simx-host-hid probe` ~50ms + `simx-host-hid axp-probe` ~50ms)，单测全 mock probe 函数无法证明真 wiring（决策 5 字面：C 路径真子进程，单测 mock = 等同 mock 整 wiring 函数，与 mock probe 等价无新信息）；e2e gate 是 C4 真生效的最终证明。本机 `claude -p ping --tools ""` 已实测 exit 0 + stdout "pong" (~3s)，Gate 4/6 可真盘过；Gate 7 是关键 regression gate——v0.4 acceptance 21 字段全保不退化是 C4 通过的硬条件。
