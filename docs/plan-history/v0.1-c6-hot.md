## 目标 checkpoint

**C6**：在 C5 的 `SimctlDriver` + `SimctlClient` + `SimSession` 之上，新增 **2 个 CLI 子命令** + **1 个真实 e2e 测试**：

### A. CLI 子命令（2 个；锁定，无分叉）

| 子命令 | 行为 | 走的底层 |
|---|---|---|
| `simx list` | 列出所有 `isAvailable=true` 的模拟器，1 行/设备：`<udid>  <state>  <name>  <runtimeIdentifier>`；exit 0 | `SimctlClient.listDevices()`（**真 simctl**） |
| `simx run <file>` | 加载 1 个 `.test.ts` 文件 → 拉 `acquireSession` → 用 `SimctlDriver` 跑 `run({ driver })` → 报告 passed/failed → 失败 exit 1，全过 exit 0 | `acquireSession` + `SimctlDriver` + `src/sdk/test.ts` |

**`simx run` 的 device 选择策略（已锁定）**：
- `--udid <udid>`：精确选；缺失 → 走 `acquireSession` 的"无 filter"路径并要求 candidates.length === 1
- `--device <name>`：传 `deviceName` 给 `acquireSession`
- `--runtime <id>`：传 `runtimeIdentifier` 给 `acquireSession`
- 均缺：CLI 在调 `acquireSession` 之前**自己先做一次 `listDevices()`，挑第一个 `isAvailable && state === 'Booted'` 的设备并用其 `udid` 调 `acquireSession({ udid })`**。理由：避免 `acquireSession` 在多设备本机抛 `DEVICE_AMBIGUOUS`（本机当前 2 booted、2 available，正好踩坑）；优先复用 booted 设备契合 v1.md 风险表"模拟器在 CI 启动慢 → 预 boot pool；run 默认复用已 boot 实例"
- 若 listDevices() 没有任何 booted 但有 available：fallback 到第一个 available（acquireSession 会自动 boot）
- 若 listDevices() 完全为空：抛 `DEVICE_NOT_FOUND`（透传）

**不实现**（C6 范围外，留 C7+ / v0.2+）：
- `simx doctor`（C7 单独 checkpoint）
- `simx boot` / `simx repl` / `simx mcp`（v0.5+ / v1.0）
- `simx run` 跑多个文件（v0.1 出口验收只跑单文件 `screenshot-only.test.ts`；多文件 glob 推到 v0.2）
- `--help` / `--version` citty 自带；不另写代码
- watch 模式

  export type WritableLike = { write: (chunk: string) => void }

  export type RunListDeps = {
    client: Pick<SimctlClient, 'listDevices'>
    out: WritableLike
    err: WritableLike
  }

  export type CommandResult = { exitCode: number }

  export async function runListCommand(deps: RunListDeps): Promise<CommandResult> {
    try {
      const devices = await deps.client.listDevices()
      for (const d of devices) {
        if (!d.isAvailable) continue
        deps.out.write(`${d.udid}  ${d.state}  ${d.name}  ${d.runtimeIdentifier}\n`)
      }
      return { exitCode: 0 }
    } catch (err) {
      const msg = err instanceof Error ? err.message : String(err)
      deps.err.write(`simx list failed: ${msg}\n`)
      return { exitCode: 1 }
    }
  }

**绿（实现）**

- 文件 1：`src/cli/commands/run.ts`（**覆盖** S1 的 stub）
  ```ts
  import { pathToFileURL } from 'node:url'
  import { mkdir, writeFile, stat } from 'node:fs/promises'
  import { dirname, join, resolve } from 'node:path'
  import { SimctlClient, type SimctlDevice } from '../../sim/simctl.js'
  import { acquireSession, SimSession } from '../../sim/session.js'
  import { SimctlDriver } from '../../driver/simctl-driver.js'
  import type { Driver } from '../../driver/index.js'
  import { run as runRegistry, resetRegistry, listTests } from '../../sdk/test.js'
  import { ExpectationFailure } from '../../core/index.js'
  import type { WritableLike, CommandResult } from './list.js'

  export type DeviceSelect = {
    udid?: string | undefined
    deviceName?: string | undefined
    runtimeIdentifier?: string | undefined
  }

  export type RunRunDeps = {
    client: SimctlClient
    file: string
    select: DeviceSelect
    out: WritableLike
    err: WritableLike
    cwd: string
  }

  export async function runRunCommand(deps: RunRunDeps): Promise<CommandResult> {
    resetRegistry()

    // 1) load TS test file via dynamic import
    const abs = resolve(deps.cwd, deps.file)
    try {
      await stat(abs)
    } catch {
      deps.err.write(`cannot load test file: ${abs}\n`)
      return { exitCode: 1 }
    }
    try {
      await import(pathToFileURL(abs).href)
    } catch (err) {
      const msg = err instanceof Error ? err.message : String(err)
      deps.err.write(`cannot load test file: ${msg}\n`)
      return { exitCode: 1 }
    }

    // 2) device selection
    let session: SimSession
    try {
      session = await pickSession(deps.client, deps.select)
    } catch (err) {
      const msg = err instanceof Error ? err.message : String(err)
      deps.err.write(`device selection failed: ${msg}\n`)
      return { exitCode: 1 }
    }

    // 3) build driver + tracing wrapper
    const base = new SimctlDriver(session)
    const tracer = new TracingDriver(base, join(deps.cwd, '.simx', 'trace'))

    // 4) run registry
    try {
      const result = await runRegistry({ driver: tracer })
      deps.out.write(`${result.passed} passed, ${result.failed} failed\n`)
      for (const f of result.failures) {
        const rendered = f.error instanceof ExpectationFailure
          ? f.error.toPrompt()
          : `${f.error.name}: ${f.error.message}`
        deps.err.write(`FAIL ${f.name}\n${rendered}\n`)
      }
      return { exitCode: result.failed === 0 ? 0 : 1 }
    } finally {
      await session.release().catch(() => {})
    }
  }

  async function pickSession(client: SimctlClient, select: DeviceSelect): Promise<SimSession> {
    if (select.udid !== undefined || select.deviceName !== undefined || select.runtimeIdentifier !== undefined) {
      return acquireSession(select, { client })
    }
    // default: pick first booted available device to avoid DEVICE_AMBIGUOUS
    const all = await client.listDevices()
    const booted = all.find((d) => d.isAvailable && d.state === 'Booted')
    if (booted !== undefined) {
      return acquireSession({ udid: booted.udid }, { client })
    }
    const available = all.find((d) => d.isAvailable)
    if (available !== undefined) {
      return acquireSession({ udid: available.udid }, { client })
    }
    return acquireSession({}, { client })  // will throw DEVICE_NOT_FOUND with details
  }

  // Wraps SimctlDriver so screenshot()/describe() also persist PNGs to .simx/trace/<case>/.
  // The current case name is tracked via SDK test() callback boundary — but the
  // SDK runner doesn't expose per-case hooks today. So we use a counter scheme:
  // wrapper holds a monotonic seq + the current "case slug", which the caller
  // sets via setCase() before each c.fn invocation. Simplest impl: use SDK's
  // run() result.failures to know names; but we need NAME during execution.
  // → Instead: intercept by reading listTests() prior to run; the runner is
  // sequential, so we maintain an index that ticks per-case via a hook into
  // run().
  class TracingDriver implements Driver { /* delegate every Driver method to base except screenshot/describe; see below */ }
  ```

  TracingDriver 完整骨架：
  ```ts
  class TracingDriver implements Driver {
    private currentSlug: string | undefined
    private seq = 0
    constructor(private readonly base: Driver, private readonly traceRoot: string) {}

    beginCase(slug: string): void { this.currentSlug = slug; this.seq = 0 }

    async screenshot(): Promise<Buffer> {
      const png = await this.base.screenshot()
      if (this.currentSlug !== undefined) {
        this.seq += 1
        const num = String(this.seq).padStart(4, '0')
        const out = join(this.traceRoot, this.currentSlug, `${num}-screenshot.png`)
        await mkdir(dirname(out), { recursive: true })
        await writeFile(out, png)
      }
      return png
    }
    // delegate everything else; 28 methods (Driver 29 minus screenshot)
    // describe(): we DON'T persist describe's png separately to avoid double-write
    //   when test does `await app.screenshot()` followed by app.describe();
    //   C6 trace only writes when app.screenshot() is called.
    describe(): ReturnType<Driver['describe']> { return this.base.describe() }
    launch(...args: Parameters<Driver['launch']>): ReturnType<Driver['launch']> { return this.base.launch(...args) }
    // ... 27 more delegates ...
  }
  ```
