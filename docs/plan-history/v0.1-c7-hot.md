## 目标 checkpoint

**C7**：在 C6 的 `simx list` / `simx run` 之上，新增 1 个 CLI 子命令 `simx doctor`。**只**探测 4 项：
1. Xcode 版本（`xcodebuild -version` 首行，匹配 `/^Xcode \d+\./`）
2. 可用 iOS runtime 数（复用 `SimctlClient.listRuntimes()`，count ≥ 1）
3. `claude` CLI 是否在 PATH（**只判断存在性**；不验证登录态/帐号/quota）
4. bun 版本（`process.versions.bun`，semver ≥ `1.1.0`）

每项产出 `{ name, ok, value?, message? }`。整体结构：
```ts
type DoctorReport = {
  exitCode: 0 | 1                       // 0 iff every check.ok === true
  checks: ReadonlyArray<DoctorCheck>    // 顺序固定：xcode, runtimes, claude, bun
}
type DoctorCheck = {
  name: 'xcode' | 'runtimes' | 'claude' | 'bun'
  ok: boolean
  value?: string                        // 已探到的事实，如 "Xcode 26.4.1"、"3" 个 runtime
  message?: string                      // ok=false 时的人类可读说明 + 修复线索
}
```

**输出格式**（锁定，无分叉）：
- **默认（human）**：每行 `<icon> <name>: <message-or-value>`；`icon` = `✓`（ok）/ `✗`（fail）。最后无总结行（exitCode 已传递结果）
- **`--json`**：单行 `JSON.stringify({ exitCode, checks })`，stdout 一次性写完，末尾换行

**CLI 退出码**：所有 4 项 `ok=true` → `exit 0`；任一 `ok=false` → `exit 1`。

**完整 doctor（v0.5 留）不做**：私有符号 dlsym 探测（Indigo / AccessibilityPlatformTranslation）、`claude` 登录态、9-arg Indigo 探针、testmanagerd health、HID 路径自检、`--fix` 修复模式。

**绿（实现）**

- 文件 1：`src/cli/commands/doctor.ts`（新建）
  ```ts
  import type { WritableLike, CommandResult } from './list.js'

  export type ProbeXcode = () => Promise<string>          // resolves to xcodebuild stdout line 1; rejects on exec failure
  export type ProbeRuntimes = () => Promise<number>       // resolves to count of available iOS runtimes
  export type ProbeClaude = () => Promise<string | undefined>  // resolves to absolute path if found, else undefined
  export type ProbeBun = () => string | undefined         // synchronous: process.versions.bun

  export type DoctorCheckName = 'xcode' | 'runtimes' | 'claude' | 'bun'

  export type DoctorCheck = {
    name: DoctorCheckName
    ok: boolean
    value?: string
    message?: string
  }

  export type DoctorReport = {
    exitCode: 0 | 1
    checks: ReadonlyArray<DoctorCheck>
  }

  export type RunDoctorDeps = {
    probeXcode: ProbeXcode
    probeRuntimes: ProbeRuntimes
    probeClaude: ProbeClaude
    probeBun: ProbeBun
    json: boolean
    out: WritableLike
    err: WritableLike
  }

  const MIN_BUN = '1.1.0'

  export async function runDoctorCommand(deps: RunDoctorDeps): Promise<CommandResult> {
    const checks: DoctorCheck[] = [
      await checkXcode(deps.probeXcode),
      await checkRuntimes(deps.probeRuntimes),
      await checkClaude(deps.probeClaude),
      checkBun(deps.probeBun),
    ]
    const exitCode: 0 | 1 = checks.every((c) => c.ok) ? 0 : 1

    if (deps.json) {
      deps.out.write(`${JSON.stringify({ exitCode, checks })}\n`)
    } else {
      for (const c of checks) {
        const icon = c.ok ? '✓' : '✗'
        const tail = c.ok ? (c.value ?? '') : (c.message ?? 'failed')
        deps.out.write(`${icon} ${c.name}: ${tail}\n`)
      }
    }
    return { exitCode }
  }

  async function checkXcode(probe: ProbeXcode): Promise<DoctorCheck> {
    try {
      const line = (await probe()).trim()
      if (/^Xcode \d+\./.test(line)) {
        return { name: 'xcode', ok: true, value: line }
      }
      return { name: 'xcode', ok: false, value: line, message: `unexpected output: ${line}` }
    } catch (err) {
      const msg = err instanceof Error ? err.message : String(err)
      return { name: 'xcode', ok: false, message: `xcodebuild failed: ${msg}` }
    }
  }

  async function checkRuntimes(probe: ProbeRuntimes): Promise<DoctorCheck> {
    try {
      const n = await probe()
      if (n >= 1) return { name: 'runtimes', ok: true, value: String(n) }
      return { name: 'runtimes', ok: false, value: String(n), message: 'no iOS runtime installed' }
    } catch (err) {
      const msg = err instanceof Error ? err.message : String(err)
      return { name: 'runtimes', ok: false, message: `simctl list runtimes failed: ${msg}` }
    }
  }

  async function checkClaude(probe: ProbeClaude): Promise<DoctorCheck> {
    try {
      const path = await probe()
      if (path !== undefined && path.length > 0) {
        return { name: 'claude', ok: true, value: path }
      }
      return { name: 'claude', ok: false, message: 'claude not found in PATH (install Claude Code)' }
    } catch (err) {
      const msg = err instanceof Error ? err.message : String(err)
      return { name: 'claude', ok: false, message: `claude probe failed: ${msg}` }
    }
  }

  function checkBun(probe: ProbeBun): DoctorCheck {
    const v = probe()
    if (v === undefined) {
      return { name: 'bun', ok: false, message: `not running under bun; requires bun >= ${MIN_BUN}` }
    }
    if (gteSemver(v, MIN_BUN)) {
      return { name: 'bun', ok: true, value: v }
    }
    return { name: 'bun', ok: false, value: v, message: `requires bun >= ${MIN_BUN}, got ${v}` }
  }

  function gteSemver(a: string, b: string): boolean {
    const pa = a.split('.').map((x) => Number.parseInt(x, 10))
    const pb = b.split('.').map((x) => Number.parseInt(x, 10))
    for (let i = 0; i < 3; i += 1) {
      const ai = pa[i] ?? 0
      const bi = pb[i] ?? 0
      if (Number.isNaN(ai) || Number.isNaN(bi)) return false
      if (ai > bi) return true
      if (ai < bi) return false
    }
    return true
  }
  ```
- 关键点：
  - **每项探测互不依赖**（即使 xcode 失败，runtimes/claude/bun 也照常探）
  - **不**引 chalk / colors；✓ / ✗ 是裸 UTF-8 字符
  - `MIN_BUN = '1.1.0'` 硬编码与 `package.json#engines.bun = ">=1.1.0"` 一致；**不**抽到常量文件（YAGNI；仅 1 处用）
  - `gteSemver` 仅做 3 段数字比较，足以判 `1.3.13 >= 1.1.0`；不需要完整 semver 库
  - JSON 输出严格遵循 `DoctorReport` 形状，AI-readable（不变量 §9.5）
  - 4 项顺序固定：xcode → runtimes → claude → bun（输出稳定、可断言）

    ```ts
    const doctorCommand = defineCommand({
      meta: { name: 'doctor', description: 'Diagnose environment (Xcode, iOS runtimes, claude, bun)' },
      args: {
        json: { type: 'boolean', description: 'output JSON instead of human-readable', default: false },
      },
      async run({ args }) {
        const client = new SimctlClient()
        const res = await runDoctorCommand({
          probeXcode: async () => {
            const { stdout } = await execFileP('xcodebuild', ['-version'])
            return stdout.split('\n')[0] ?? ''
          },
          probeRuntimes: async () => {
            const rs = await client.listRuntimes()
            return rs.filter((r) => r.isAvailable).length
          },
          probeClaude: async () => {
            try {
              const { stdout } = await execFileP('command', ['-v', 'claude'], { shell: '/bin/sh' as unknown as boolean })
              const path = stdout.trim()
              return path.length > 0 ? path : undefined
            } catch {
              return undefined
            }
          },
          probeBun: () => process.versions.bun,
          json: args.json === true,
          out: process.stdout,
          err: process.stderr,
        })
        process.exit(res.exitCode)
      },
    })
    ```

- **关于 `which claude` 探测**：`execFile('command', ['-v', 'claude'], { shell: '/bin/sh' })` 走 sh builtin，跨 zsh/bash 通用、不需要 `which` 二进制。**WHY**：`which` 在某些发行版（Alpine、bare CI）缺失；`command -v` 是 POSIX 标准。
  - 实际上 `node:child_process` 的 `execFile` 的 options 没有 `shell: string` 字段，而是 `shell?: boolean | string`。本计划写法 `shell: '/bin/sh' as unknown as boolean` 是为通过 strict 类型；**更干净**做法是改用 `exec`（默认 shell）：
    ```ts
    import { exec as execCb } from 'node:child_process'
    const execP = promisify(execCb)
    // ...
    probeClaude: async () => {
      try {
        const { stdout } = await execP('command -v claude', { shell: '/bin/sh' })
        const p = stdout.trim()
        return p.length > 0 ? p : undefined
      } catch {
        return undefined
      }
    },
    ```
    **决策：采用 `exec` 形态**（types 干净；CLAUDE.md §8.3 禁止无 WHY 的 `as any`/`as unknown`）。
