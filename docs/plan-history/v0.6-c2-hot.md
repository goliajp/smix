## 目标 checkpoint

**C2**：通过后世界变成 — `bun src/cli/index.ts mcp` 字面启动 stdio MCP server 同时 expose 8 个 tool（C1 `ping` + C2 新加 7 lifecycle），每 tool 真接 `SimctlClient`：

- `tools/list` → 返 8 element array，名字字面：`ping` / `simulator_list` / `simulator_boot` / `simulator_shutdown` / `app_launch` / `app_terminate` / `app_install` / `app_uninstall`
- `tools/call name=simulator_list arguments={}` → 返 `{content:[{type:'text', text: '{"devices":[{udid, name, state, isAvailable, runtimeIdentifier, deviceTypeIdentifier}, ...]}'}]}`（structured JSON 序列化为单 text content）
- `tools/call name=simulator_boot arguments={udid:"..."}` → boot 完成 → 返 `{content:[{type:'text', text:'{"udid":"...", "name":"...", "state":"Booted", "alreadyBooted":false, "durationMs":N}'}]}`
- `tools/call name=simulator_boot arguments={name:"iPhone 16 Pro"}` → 同上但通过 name resolve（支持 `udid` 或 `name`，互斥决策 9.A）
- `tools/call name=simulator_shutdown arguments={udid:"..."}` → 返 `{content:[{type:'text', text:'{"udid":"...", "ok":true}'}]}`
- `tools/call name=app_launch arguments={udid:"...", bundleId:"com.apple.Preferences"}` → 返 `{content:[{type:'text', text:'{"pid":N}'}]}`
- `tools/call name=app_launch arguments={udid:"...", bundleId:"...", launchArguments:["-x","y"]}` → 同上（args 透传给 `client.launch(udid, bundleId, args, {})`）
- `tools/call name=app_terminate arguments={udid:"...", bundleId:"..."}` → 返 `{content:[{type:'text', text:'{"udid":"...", "bundleId":"...", "ok":true}'}]}`
- `tools/call name=app_install arguments={udid:"...", appPath:"/path/to/foo.app"}` → 返 `{content:[{type:'text', text:'{"ok":true}'}]}`
- `tools/call name=app_uninstall arguments={udid:"...", bundleId:"..."}` → 返 `{content:[{type:'text', text:'{"ok":true}'}]}`
- 任一 tool 失败（device not found / simctl exit !=0 / launch 输出无 PID）→ `{isError:true, content:[{type:'text', text:'<error message>'}]}`（决策 10.A——SDK 不抛 JSON-RPC error，前端 AI 易消费）
- `tools/call name=simulator_boot arguments={}`（既无 udid 也无 name）→ `{isError:true, content:[{type:'text', text:'invalid arguments: ...'}]}`（zod refine + SDK 默认 isError 路径）

  import type { SimctlDevice } from '../sim/simctl.js'

  // Strict UUID v4 form (8-4-4-4-12 hex) — avoids misclassifying device names
  // that contain '-' (e.g. 'iPad Pro 11-inch (M4)') as UDIDs.
  export const UUID_RE = /^[0-9A-Fa-f]{8}-[0-9A-Fa-f]{4}-[0-9A-Fa-f]{4}-[0-9A-Fa-f]{4}-[0-9A-Fa-f]{12}$/

  export function resolveDevice(
    all: readonly SimctlDevice[],
    query: string,
  ): SimctlDevice[] {
    if (UUID_RE.test(query)) {
      return all.filter((d) => d.udid === query && d.isAvailable)
    }
    return all.filter((d) => d.name === query && d.isAvailable)
  }

  export function describeQuery(query: string): string {
    return UUID_RE.test(query) ? `udid: '${query}'` : `name: '${query}'`
  }

## 7 tool input/output schema 摘要

| Tool | Input (zod) | Output JSON (string in content[0].text) |
|---|---|---|
| `simulator_list` | `{}` strict | `{"devices":[{"udid":string,"name":string,"state":string,"isAvailable":boolean,"runtimeIdentifier":string,"deviceTypeIdentifier":string}, ...]}` |
