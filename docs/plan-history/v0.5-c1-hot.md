## 目标 checkpoint

**C1：`bun src/cli/index.ts repl --udid <UDID>` 启动 readline 交互；每行命令真触发 `app.<verb>` SDK 调用；每个非 `.dot` 命令后自动 `app.describe()` 拿 top-5 元素打 stdout；语法错 / 运行时错都 print hint 不退出；`.exit` / ctrl-D 优雅退出 (exit code 0)。**

通过后世界变成：

- **REPL 命令语法（决策 1：A 字面 SDK shell-like 风格）**——5 verb + 2 meta 严格白名单：

  ```
  launch <bundleId>              # app.launch(bundleId)
  terminate <bundleId>           # app.terminate(bundleId)
  tap <selector-str>             # app.tap(parsedSelector)
  screenshot                     # app.screenshot()
  describe                       # app.describe()，渲染 top-5 + 真打 frontApp/capturedAt 摘要头
  .help                          # 打印 verb 用法
  .exit                          # 优雅退出 exit code 0
  ```

  *注：v0.5 C1 lock 5 个 user-facing action verb + 2 个 meta verb*——cold plan 字面"一行调用"已字面覆盖（`launch com.apple.Preferences\ntap text=General\n.exit` 是 cold plan 出口验收最小集合）。`doubleTap / longPress / fill / clear / swipe / scroll / pressKey / hideKeyboard / openUrl / pasteboard.get / pasteboard.set / permissions.grant / setAppearance / setLocale / setNetwork / waitFor` 16 个 verb 推 C2/C3（**决策 1.b**：`.save` 时 selector 抽取 + reverse-replay 需要这些 verb；C1 5 个动作覆盖 happy path "launch + tap"）。

- **selector grammar（决策 2：单 base 无 modifier 严格）**——4 base form：

  ```
  text=<value>                   # → { text: '<value>' }
  id=<value>                     # → { id: '<value>' }
  label=<value>                  # → { label: '<value>' }
  role=<role>[,name=<name>]      # → { role: '<role>', name: '<name>' }
  ```

  *注*：
  - 值不带引号 = 字面字符串，逗号 / 空格 / 末尾换行截断 (`tap text=General Settings` parse `{text:'General Settings'}`，仅顶层 `,` 分隔 modifier key——但 C1 不支持 modifier，所以实质 `,` 也字面)；
  - **C1 严格 string**：不 parse RegExp 字面（决策 2 拒绝 D：`tap text=/General/i` 当字面字符串解，AI 习惯了；regex parse 推 C5）；
  - **role grammar**：`role=button` ok / `role=button,name=General` ok / `role=button,name=` parse 失败 hint "name= must have value"；
  - 不支持多 modifier：`tap text=General,below=text=Settings` 严格 parse 失败 hint "modifier not supported in C1 (see C5)"

- **describe 摘要渲染（决策 3：top-5 visibleElements，DFS pre-order，单行 plain text）**——每个非 `.dot` 命令后：

  ```
  → screen: <frontApp> @ <capturedAt-ISO>
    1. role=<role> name="<name>" id="<id>" bounds=(x,y,w,h)
    2. ...
    5. ...
  ```

  *注*：
  - top-N = **5 严格**（cold plan 字面 "top 5"）；元素 < 5 时全打；0 时打 "→ screen: <frontApp> (no visible elements)"；
  - **排序**：直接取 `screen.elements.slice(0, 5)`——`elements` 已是 DFS pre-order (v0.4 C1 决策 2 字面)，不再排序；
  - **不按距离 cursor 排序**（决策 3 拒绝 B：cursor 概念在 TUI 模式有意义，REPL 是行模式无 cursor）；
  - **不按 cell.runnerPort 标 prefix**（决策 3 拒绝 C：cell-aware 渲染推 v1.1 multi-cell）；
  - **每命令都打**（包括 `screenshot` / `describe` 自己；`screenshot` 后顺手 describe 让 AI 知道屏幕 + 拿到 PNG buffer——不写盘只 console.log "→ screenshot: <bytes> bytes captured"）；
  - **`.dot` 命令不触发 describe**（`.help` / `.exit` 是 meta，无屏幕状态）；
  - describe 自己失败 → 单行 hint `"→ describe failed: <message>"` 不退出 REPL。

- **错误处理（决策 6：所有错误 print hint 不退出 REPL）**：
  - parser 错（语法）：`error: unknown verb 'foo'; type .help for list`
  - parser 错（selector）：`error: bad selector 'text='; expected text=<value>` / `error: modifier not supported in C1`
  - 运行时 `TapNotFoundError` (404)：`error: tap not found for selector {text:'X'}; type 'describe' to see visible elements`
  - 运行时 `RunnerTransportError`：`error: runner transport: <message>; check simctl + runner process is alive`
  - 运行时 `ExpectationFailure`：`error: ELEMENT_NOT_FOUND: <message>` (driver 已构造，直接 reuse `.code + .message`)
  - 其他 throw：`error: <name>: <message>` (best-effort)
  - **任何错误 print 后 REPL 自动进入下一 prompt**（readline.prompt() 重新触发）

- **REPL 启动行为（决策 5：device selection 复用 run）**：
  - `--udid` / `--device` / `--runtime` 显示传入 → `pickCell` 同 run.ts 语义；
  - 无 arg → first booted available（同 run.ts default）；
  - 启动后打印 banner：`simx repl — Cell ${cell.id} @ ${cell.udid}\nDriver: SimctlDriver (runner :${cell.runnerPort})\nType .help for commands, .exit to quit.`
  - 然后 `prompt = '> '` 进入循环

- **退出行为（决策 9）**：
  - `.exit` / EOF (ctrl-D，readline 'close' 事件) → 调 `releaseCell(cell, {shutdown:false})`（不 shutdown sim，与 run.ts default 对齐——sim 是 host 共享资源）→ exit code 0
  - signal SIGINT (ctrl-C) → readline 默认 newline 行为（不退出，类似 node REPL）；连按两次 → exit code 0（决策 9.b：与 node REPL 同形态降低学习成本）

- **测试基线**：320 → **~346** TS (16-20 parser + 10 dispatcher/lifecycle case)；swift 102 → **102**（0 改动）

- **不退化**：v0.4 acceptance 21 字段全保；既有 320 vitest case 全保（+ 26 新增）；102 swift 全保；6-check doctor 全保；typecheck 0 error 全保。

### F2. `pickCell` 形态（`src/cli/commands/run.ts` line 95-122，lift 为 export）

```ts
async function pickCell(
  client: SimctlClient,
  select: DeviceSelect,
): Promise<Cell> {
  if (select.udid !== undefined || select.deviceName !== undefined || select.runtimeIdentifier !== undefined) {
    const opts: AcquireCellOptions = {}
    // ...
    return acquireCell(opts, { client })
  }
  // Default: prefer first booted available device
  const all = await client.listDevices()
  const booted = all.find((d) => d.isAvailable && d.state === 'Booted')
  if (booted !== undefined) return acquireCell({ udid: booted.udid }, { client })
  const available = all.find((d) => d.isAvailable)
  if (available !== undefined) return acquireCell({ udid: available.udid }, { client })
  return acquireCell({}, { client })
}
```

C1 改动**仅** `async function` → `export async function`——0 行为变化。`DeviceSelect` type 已 export（line 24-28）。

### F7. readline event-driven 形态（node:readline stdlib，0 dep）

C1 用 callback API（不用 promises 形态，更易测）：

```ts
import { createInterface } from 'node:readline'
const rl = createInterface({ input, output, prompt: '> ' })
```

### F9. parser 状态机（无需 regex hell）

`parseReplLine(line: string)` 步骤：
1. trim；空行 → `{kind:'noop'}`
2. 首字符 `.` → meta verb 路径 (`.help` / `.exit`)；未知 `.foo` → `{kind:'error', message:"unknown meta '.foo'"}`
3. 否则 split on first whitespace → `[verb, ...rest]`
4. verb in `['launch','terminate','screenshot','describe']` → 简单 verb 路径
   - `launch <bid>` / `terminate <bid>` 要求 1 个非空 arg
   - `screenshot` / `describe` 不允许 trailing arg (严格)
5. verb === `tap` → 把 rest join 回 string，调 `parseSelectorString(s)`：
   - 切 first `=` → `[key, value]`
   - key in `['text','id','label']` → `{<key>: value}` (value 整段 trailing string，含空格)
   - key === `role` → 切 first `,` → 前段 = role value，后段 (optional) = `name=<v>`；再切 first `=` → 解析 name
   - 其他 key → 错（含 `near` / `below` / 等 modifier key — hint "modifier not supported in C1"）
6. 未知 verb → `{kind:'error', message:"unknown verb '<v>'; type .help"}`

测试时可单独测 parser 输出 ParsedCommand discriminated union，不耦合 readline。

```ts
import type { Selector } from '../../core/index.js'
import type { Role } from '../../core/index.js'

export type ParsedCommand =
  | { kind: 'noop' }
  | { kind: 'meta'; verb: '.exit' | '.help' }
  | { kind: 'verb'; verb: 'launch'; arg: string }
  | { kind: 'verb'; verb: 'terminate'; arg: string }
  | { kind: 'verb'; verb: 'screenshot' }
  | { kind: 'verb'; verb: 'describe' }
  | { kind: 'verb'; verb: 'tap'; selector: Selector }
  | { kind: 'error'; message: string }

const MOD_KEYS = ['near','below','above','leftOf','rightOf','inside','nth','first','last']

export function parseReplLine(raw: string): ParsedCommand {
  const line = raw.trim()
  if (line.length === 0) return { kind: 'noop' }
  if (line.startsWith('.')) {
    if (line === '.exit') return { kind: 'meta', verb: '.exit' }
    if (line === '.help') return { kind: 'meta', verb: '.help' }
    const metaTok = line.split(/\s+/)[0]
    return { kind: 'error', message: `unknown meta '${metaTok}'; type .help for list` }
  }
  const m = /^(\S+)(?:\s+(.*))?$/.exec(line)
  if (!m) return { kind: 'error', message: 'parse failure' }
  const verb = m[1]!
  const rest = (m[2] ?? '').trim()
  switch (verb) {
    case 'launch':
    case 'terminate':
      if (rest.length === 0) return { kind: 'error', message: `${verb} requires a bundleId` }
      return { kind: 'verb', verb, arg: rest }
    case 'screenshot':
    case 'describe':
      if (rest.length > 0) return { kind: 'error', message: `${verb} takes no arguments` }
      return { kind: 'verb', verb }
    case 'tap':
      if (rest.length === 0) return { kind: 'error', message: 'tap requires a selector (e.g. text=General)' }
      return parseTapSelector(rest)
    default:
      return { kind: 'error', message: `unknown verb '${verb}'; type .help for list` }
  }
}

function parseTapSelector(s: string): ParsedCommand {
  if (s.includes(',')) {
    const head = s.split(',')[0]!
    const tail = s.split(',').slice(1).join(',')
    if (head.startsWith('role=')) {
      const roleVal = head.slice(5)
      if (roleVal.length === 0) return { kind: 'error', message: 'bad selector: role= must have value' }
      const nameMatch = /^name=(.*)$/.exec(tail)
      if (!nameMatch) return { kind: 'error', message: `modifier not supported in C1: '${tail.split('=')[0]}' (推 v0.5 C5)` }
      const nameVal = nameMatch[1]!
      if (nameVal.length === 0) return { kind: 'error', message: 'bad selector: name= must have value' }
      return { kind: 'verb', verb: 'tap', selector: { role: roleVal as Role, name: nameVal } }
    }
    const modKey = tail.split('=')[0] ?? ''
    return { kind: 'error', message: `modifier not supported in C1: '${modKey}' (推 v0.5 C5)` }
  }
  const eq = s.indexOf('=')
  if (eq <= 0) return { kind: 'error', message: `bad selector '${s}'; expected text=|id=|label=|role=` }
  const key = s.slice(0, eq)
  const val = s.slice(eq + 1)
  if (val.length === 0) return { kind: 'error', message: `bad selector: ${key}= must have value` }
  if (key === 'text') return { kind: 'verb', verb: 'tap', selector: { text: val } }
  if (key === 'id') return { kind: 'verb', verb: 'tap', selector: { id: val } }
  if (key === 'label') return { kind: 'verb', verb: 'tap', selector: { label: val } }
  if (key === 'role') return { kind: 'verb', verb: 'tap', selector: { role: val as Role } }
  if (MOD_KEYS.includes(key)) return { kind: 'error', message: `modifier not supported in C1: '${key}' (推 v0.5 C5)` }
  return { kind: 'error', message: `bad selector '${s}'; expected text=|id=|label=|role=` }
}
```

```ts
import type { Readable } from 'node:stream'
import { App } from '../../sdk/index.js'
import { ExpectationFailure } from '../../core/index.js'
import type { ScreenDescription, ElementSummary } from '../../core/index.js'
import { TapNotFoundError, RunnerTransportError } from '../../sim/runner-client.js'
import type { Cell } from '../../sim/cell.js'
import { releaseCell } from '../../sim/cell.js'
import type { WritableLike, CommandResult } from './list.js'
import { parseReplLine, type ParsedCommand } from './repl-parser.js'

export type RunReplDeps = {
  app: App
  cell: Cell
  input: Readable
  output: WritableLike
  err: WritableLike
}

const HELP = [
  'simx repl commands:',
  '  launch <bundleId>          launch app by bundle id',
  '  terminate <bundleId>       terminate app',
  '  tap <selector>             tap element; selector = text=X | id=X | label=X | role=X[,name=Y]',
  '  screenshot                 capture screen PNG',
  '  describe                   print top-5 visible elements',
  '  .help                      this list',
  '  .exit                      quit (or ctrl-D)',
].join('\n')

export async function runReplCommand(deps: RunReplDeps): Promise<CommandResult> {
  const { app, cell, input, output, err } = deps
  output.write(`simx repl — Cell ${cell.id} @ ${cell.udid}\n`)
  output.write(`Driver: SimctlDriver (runner :${cell.runnerPort})\n`)
  output.write('Type .help for commands, .exit to quit.\n')

  const rl = createInterface({
    input,
    output: { write: (chunk: string) => output.write(chunk), end: () => {} } as unknown as NodeJS.WritableStream,
    prompt: '> ',
    terminal: false,
  })

  let exiting = false
  await new Promise<void>((resolve) => {
    rl.on('line', async (raw) => {
      const parsed = parseReplLine(raw)
      try {
        await dispatch(parsed, app, output, err)
      } catch (e) {
        err.write(`error: unexpected: ${e instanceof Error ? e.message : String(e)}\n`)
      }
      if (parsed.kind === 'meta' && parsed.verb === '.exit') {
        exiting = true
        rl.close()
        return
      }
      if (!exiting) rl.prompt()
    })
    rl.on('close', () => resolve())
    rl.prompt()
  })

  try { await releaseCell(cell, { shutdown: false }) } catch { /* silent */ }
  return { exitCode: 0 }
}

async function dispatch(
  cmd: ParsedCommand,
  app: App,
  output: WritableLike,
  err: WritableLike,
): Promise<void> {
  switch (cmd.kind) {
    case 'noop':
      return
    case 'error':
      err.write(`error: ${cmd.message}\n`)
      return
    case 'meta':
      if (cmd.verb === '.help') output.write(HELP + '\n')
      return
    case 'verb':
      await runVerb(cmd, app, output, err)
      return
  }
}

async function runVerb(
  cmd: Extract<ParsedCommand, { kind: 'verb' }>,
  app: App,
  output: WritableLike,
  err: WritableLike,
): Promise<void> {
  try {
    switch (cmd.verb) {
      case 'launch':
        await app.launch(cmd.arg)
        break
      case 'terminate':
        await app.terminate(cmd.arg)
        break
      case 'tap':
        await app.tap(cmd.selector)
        break
      case 'screenshot': {
        const buf = await app.screenshot()
        output.write(`→ screenshot: ${buf.length} bytes captured\n`)
        break
      }
      case 'describe':
        // explicit describe — render in auto-describe step below; no-op here
        break
    }
  } catch (e) {
    err.write(formatError(e) + '\n')
    return
  }
  try {
    const screen = await app.describe()
    renderTop5(screen, output)
  } catch (e) {
    err.write(`→ describe failed: ${e instanceof Error ? e.message : String(e)}\n`)
  }
}

function renderTop5(screen: ScreenDescription, output: WritableLike): void {
  const ts = new Date(screen.capturedAt).toISOString()
  const top = screen.elements.slice(0, 5)
  if (top.length === 0) {
    output.write(`→ screen: ${screen.frontApp} @ ${ts} (no visible elements)\n`)
    return
  }
  output.write(`→ screen: ${screen.frontApp} @ ${ts}\n`)
  top.forEach((el, i) => {
    output.write(`  ${i + 1}. ${formatElement(el)}\n`)
  })
}

function formatElement(el: ElementSummary): string {
  const name = el.name ?? '-'
  const id = el.id ?? '-'
  const b = el.bounds
  return `role=${el.role} name="${name}" id="${id}" bounds=(${b.x},${b.y},${b.w},${b.h})`
}

function formatError(e: unknown): string {
  if (e instanceof TapNotFoundError) {
    return `error: tap not found for selector ${JSON.stringify(e.selector)}; type 'describe' to see visible elements`
  }
  if (e instanceof RunnerTransportError) {
    return `error: runner transport: ${e.message}; check simctl + runner process is alive`
  }
  if (e instanceof ExpectationFailure) {
    return `error: ${e.code}: ${e.message}`
  }
  if (e instanceof Error) {
    return `error: ${e.name}: ${e.message}`
  }
  return `error: ${String(e)}`
}
```

## 决策表

| # | 决策 | 选 | 拒绝路径 | 理由 |
|---|---|---|---|---|
| 1 | REPL 命令语法 | **A 字面 SDK shell-like 风格** (`launch com.apple.Preferences` / `tap text=General`) | B JS-eval (`await app.launch(...)`) (要 vm 上下文 / try/catch / 安全沙箱；C1 范围爆) / C 混合 (verb shell-like + 复杂 selector JSON `tap {"text":"General"}`) (双语法 AI 容易混；C5 加 modifier 时再考虑) / D Playwright fluent (`app.tap().text(...)`) (与 SDK 表面不一致) | A 与 cold plan 字面"一行调用"自然映射 (`launch ... \n tap text=... \n .exit`)；与 simctl / curl shell 习惯同源；AI 一眼看懂；parser 简单 |
| 2 | C1 selector 表面 | **4 base，0 modifier，string only** (text/id/label/role+name) | D RegExp 字面 (`text=/General/i`) (parser RegExp escape + flags 复杂 + AI 误用 anchor；推 C5) / E 多 modifier (`text=X,below=text=Y`) (递归 parser + grammar 边界爆；推 C5) / F selector JSON 字面 (`tap {"text":"General"}`) (JSON.parse 错误信号差) | cold plan 字面"一行调用"happy path = `tap text=General`，base 已覆盖；modifier 推 C5（与 `.save` selector 推断同步做经济）；string only 是 v0.3 C4 resolveSelector 底层支持的最小子集，绕 RegExp 解析陷阱；C1 严格基线易测易实现 |
| 3 | top-5 describe 渲染 | **A DFS pre-order top-5 plain text** (复用 `screen.elements` 顺序 + 单行 element 摘要) | B 按 cursor 距离排序 (REPL 行模式无 cursor 概念) / C cell-prefix 渲染 (`[cell-0001] launch ...`) (multi-cell 推 v1.1) / D JSON 输出 (AI 友好但人不友好) / E 表格 (固宽列 + 多行；终端不一致) | cold plan 字面 "top 5 元素摘要"；DFS pre-order 与 v0.4 C1 `collectVisibleSummaries` 决策 2 字面对齐；plain text 单行让 AI / 人都好读；JSON 输出可推 C4 (`describe --json` flag) 一起做 |
| 4 | 是否激活 trace-sink | **不激活** | 激活：每 REPL 命令落 `.simx/trace/repl-<ts>/` (与 `simx run` 共用 sink module singleton，sink 已支持) | cold plan §资源依赖未要求 REPL 写 trace；REPL 是交互式探索 → 写盘等于污染 (user 没 case slug 概念)；`.save as <name>` (C3) 时再考虑用 trace 序列重构 TS；C1 严格不写盘等于"REPL 是无副作用沙箱"心智模型清晰 |
| 5 | device selection | **复用 `pickCell` export** | 重写 REPL 独立 selector 逻辑 (代码翻倍且与 run 形态漂移) / require `--udid` 显式 (user friction，cold plan 字面 `--device` 也支持) | run 已实测 line 95-122 形态稳；export 单 keyword 0 行为改动；`pickCell` 是 device selection 单一事实源，REPL 自然继承 first-booted-default 语义 |
| 6 | 错误处理 | **所有错误 print hint 不退出** (parser/Tap404/transport/ExpectationFailure/其他 throw) | A throw → process.exit (CI 风格但 REPL 是交互式，1 个 typo 即退出体验差) / B 仅 parser 错不退出，运行时错退出 (双轨标准 AI 难学) / C 改抛 ExpectationFailure 让 SDK catch (违反 v1.md §9.5 错误纪律 — REPL 是错误终点不是中转) | cold plan §7 字面"命令解析错 (语法) → 打印 hint 不退出；运行时错 → 打印 ExpectationFailure-style 摘要不退出"；hint 教用户下一步动词 (`type 'describe' to see visible elements`) 与 AI prompt 工程对齐 |
| 7 | `.history` 命令缓冲 | **不在 C1**（推 C2 与 `.undo`/`.redo` 一起做） | C1 加 `.history` (要 step-history Array 数据结构 + 持久化 / 仅内存 / 上限策略 — 一套小架构；与 C2 `.undo` 复用同结构，分开做翻倍工作) | cold plan C1 字面"启动 + 一行调用 + 自动 describe"——`.history` 不在 happy path；C2 `.undo` 必须维护 history，C1 加 `.history` 等于把 C2 数据结构先建一遍；分开做违反一次只到下一 checkpoint |
| 8 | e2e smoke shell | **不写**（C1 单测 + 集成 gate 6/7 已足；e2e 推 C2-C3） | 写 `scripts/simx-c1-repl-smoke.sh` (启 sim → REPL 真 launch + tap + describe → assert stdout 含 'General') (要 90s xcodebuild boot + sparse-tree 风险 + 单测已覆盖语义) | REPL 是交互式 → e2e 需要 here-string / expect 脚本，复杂度与价值不成比例；C1 集成 gate 6/7 已验启动 + parser 错路径；C2/C3 时 `.undo`/`.save` 涉及 selector 推断真实形态，e2e 价值高再一起写 |
| 9 | 退出语法 | **`.exit` + ctrl-D (EOF) + 连按 2 次 ctrl-C** (与 node REPL 同形态) | 多别名 `quit` / `q` / `:q` / `exit` (违反"AI 训练语料金标准"——`.exit` 是 node REPL 字面，AI 已学；多别名加噪声) / 强制 ctrl-D 唯一 (用户行体验差，需 newline → ctrl-D 两次按键) | node REPL 是 AI 训练语料金标准；`.exit` + ctrl-D 全覆盖 keyboard / pipeline 两路；ctrl-C 防误退（行模式下用户可能想清当前输入） |
