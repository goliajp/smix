### S1. `TreeRoute` 纯函数 + `SimxRunnerServer` 加 snapshotHandler closure + `SimxRunnerUITests` 注入 `XCUIApplication.snapshot()` 转换

> **决策依据（见末尾"关键技术决策"表 #1-#5）**：
> - **HTTP method = GET**（无 body）；endpoint = `/tree`；frontmost only（无 `bundleId` body）—— 与 v0.2 C2 `POST /tap` 对称（tap 有 selector body 用 POST；tree 无 input 用 GET 符合 REST 直觉 + 便于 `curl GET` smoke）
> - **XCUIElementSnapshot 取数路径**：UITest target closure 内 `let snap = try app.snapshot()` 同步取（snapshot() 是阻塞 throwing API，~50-100ms）；closure 返回 `A11ySnapshotData?` 内部数据（**不**直接返回 XCUIElementSnapshot 实例 — 避免 `SimxRunnerCore` lib 引入 XCTest/XCUI 依赖；与 v0.2 C2 closure 注入 TapOutcome 同模式）
> - **rawType 翻译**：**Swift 出 string raw name**（"button"/"staticText"/"cell"/...），**TS 侧不再翻译**到 Playwright Role（C3 协议固化时由 `src/core/role.ts` 的 `elementTypeToRole` 补 `role` 字段；C1 `A11yNode.role` 留 `undefined`）—— 理由：`src/core/role.ts` 已有完整 `XCUIElementType` numeric → string 表（lines 43-104）+ `elementTypeToRole(value:number)`；Swift 侧只出**字符串名**，host TS 用既有表反查 / 补 role 字段 = 避免双侧维护两份翻译表。**重要**：Swift 侧用 `XCUIElement.ElementType` 的 `rawValue: UInt` 通过**手写 switch** 转 string —— Apple 未公开 ElementType description；switch 表手写自 `src/core/role.ts` line 43-104 同构。
> - **A11yNode 字段映射**：`rawType` ← elementType name；`identifier` ← snapshot.identifier (空串 → omit)；`label` ← snapshot.label (空串 → omit)；`value` ← snapshot.value 强转 String? 后 omit-if-empty；`text` ← v0.3 C1 **不填**（XCUIElementSnapshot 无独立 text 属性；C3 协议固化时再决定 label vs text）；`bounds` ← snapshot.frame 直转 `{x,y,w,h}` (**logical points @1x**，与冷计划 C5 几何计算的预期单位对齐 — 决策 #4)；`enabled` ← snapshot.isEnabled；`selected` ← snapshot.isSelected；`hasFocus` ← v0.3 C1 占位 `false`（snapshot 无此属性 — C2/C3 AX 主路径再补）；`visible` ← `frame.intersects(app.frame) && !frame.isEmpty`（启发式 — snapshot 是 dead frame，无 live `isHittable` — 决策 #5）；`children` ← 递归。
> - **60 层深度对策**：递归带 depth 计数，**`MAX_DEPTH = 60`** 处直接 truncate（child 数组写 `[]` + 父节点加 `_truncated: true`？**不**加扩展字段 — `A11yNode` schema 不带 truncate flag，C1 静默截断 + Swift 端 stderr log 一行 warning + 单测断言。冷计划"60 层硬限"在 C3 flatten 策略时再决；C1 仅做 cliff。
> - **空 bundle / launch 未就绪**：closure 内 `try? app.snapshot()` 返回 nil → server 返回 `500 {"ok":false,"error":"snapshot_unavailable"}`；C1 单测覆盖该路径。

- 文件 1（新建）：`swift-bridge/Sources/SimxRunnerCore/TreeRoute.swift`
  - 关键签名（plan 内不写实现，仅锁形状）：
    ```swift
    public enum TreeRoute {
      // POCO — closure 注入路径，UITest target 把 XCUIElementSnapshot
      // 转成此 struct 再交给 SimxRunnerCore。Core lib 不见 XCUI。
      public struct A11ySnapshotData: Sendable {
        public let elementTypeRawValue: UInt
        public let identifier: String
        public let label: String
        public let value: String?
        public let frame: CGRect
        public let isEnabled: Bool
        public let isSelected: Bool
        public let children: [A11ySnapshotData]
        // appFrame 仅顶层用于 visible 启发式；递归层传同一值
        public init(elementTypeRawValue: UInt, identifier: String, label: String,
                    value: String?, frame: CGRect, isEnabled: Bool, isSelected: Bool,
                    children: [A11ySnapshotData])
      }

      public static func elementTypeName(_ rawValue: UInt) -> String
      public static func serialize(_ root: A11ySnapshotData, appFrame: CGRect,
                                   logSink: ((String) -> Void)?) -> Data
      public static func success(_ payload: Data) -> HTTPResponse
      public static func unavailable() -> HTTPResponse

      static let MAX_DEPTH: Int = 60
    }
    ```
  - 实现要点（绿阶段写）：
    - elementType name 用 `switch rawValue` —— **手写表** 镜像 `src/core/role.ts` line 43-104 的 50+ 条目；unknown → `"other"`（rawValue=1 也是 "other"）
    - serialize 用 `JSONSerialization` + `[String: Any]` 中间表（与 `TapRoute` 风格一致；不写 Codable）—— omit-if-empty: `if !identifier.isEmpty { dict["identifier"] = identifier }` ditto label / value
    - bounds 字段顺序：`x, y, w, h`（与 `src/core/screen.ts` Rect 一致）；w = frame.size.width；h = frame.size.height
    - visible: `let intersection = frame.intersection(appFrame); return !intersection.isNull && !intersection.isEmpty && !frame.isEmpty`
    - depth: 递归参数 `depth: Int`；`depth >= MAX_DEPTH` → children = []  + `logSink?("tree: truncated at depth \(MAX_DEPTH)")`
    - hasFocus 占位 `false`；selected = isSelected；rawType = elementTypeName
    - **不**填 role / text（C3 再补）
    - response 用 envelope helper 沿用 `TapRoute.envelope` 模式（在 TreeRoute 内复制 4 行，**不**抽公共 helper —— C3 第二次出现时再抽，YAGNI）

    ```swift
    private func convertSnapshot(_ s: XCUIElementSnapshot) -> TreeRoute.A11ySnapshotData {
      let valueStr: String? = (s.value as? String).flatMap { $0.isEmpty ? nil : $0 }
      let children = s.children.map { convertSnapshot($0) }
      return TreeRoute.A11ySnapshotData(
        elementTypeRawValue: UInt(s.elementType.rawValue),
        identifier: s.identifier,
        label: s.label,
        value: valueStr,
        frame: s.frame,
        isEnabled: s.isEnabled,
        isSelected: s.isSelected,
        children: children
      )
    }
    ```

## 关键技术决策（7 + 3 条 — 用户提示 7 个 + plan 落地 3 个）

| # | 决策点 | 选择 | 理由 |
|---|---|---|---|
| **1** | **HTTP method + endpoint** | **GET `/tree`，无 body，frontmost only** | (a) tree 取数无 input（与 tap 有 selector body 形成对称：tap=POST/tree=GET）；(b) frontmost = v0.2 C2 UITest 内 `XCUIApplication(bundleIdentifier:"com.apple.Preferences")` 已 launch — C1 沿用同 closure 注入路径；(c) **不**接收 `bundleId` body — 多 app 切换推 v0.4-v0.6 (`SimxRunnerCore` actor + multi-app 状态机要重新设计 lifecycle，超 C1 范围)；(d) `curl GET` smoke 比 `curl -X POST ... -d '{}'` 更简洁；(e) REST 直觉：safe + idempotent GET 适合 read-only 查询 |
| **2** | **snapshot 深度限制对策** | **MAX_DEPTH=60 静默截断 + Swift stderr log warning + 单测覆盖**；**不**加 `_truncated` extension 字段到 `A11yNode` schema | iOS XCUITest snapshot 硬限 60 层（v1.md §5 风险表）—— RN / Flutter 深嵌套触发后整树 unavailable。**C1 cliff 截断**保证 60 层下不抛 + 客户端始终拿到部分树。`A11yNode` schema 不带 `_truncated` —— `src/core/screen.ts:14-30` 是 v0.1 锁定型，加字段 = schema 改动 = C3 协议固化才做（决策 #5 延伸）。**flatten 策略 / a11y identifier 加注 hint** 推 C3 + 文档建议 |
| **3** | **快照 cache？** | **C1 stateless：每次 GET /tree 都重 snapshot()**；cache 推 C5 selector resolver 真生效后 | XCUI snapshot() ~50-100ms；C1 单次 e2e smoke 调 1 次，stateless 简单。**cache 利弊**：v0.3 C5 selector resolver 反复查同 tree 时 cache 5s 是优化，但**早期 cache = 早期 staleness bug**（UI 跳页后旧 cache → 错误 not_found）。C1 不引入 statefulness，server 仍 actor 但无 cache state。决策延期到 C5 真实测得 P50 > 20ms 后再加（冷计划"100 节点 P50 < 20ms"基准） |
| **4** | **bounds 单位** | **logical points @1x**（XCUIElementSnapshot.frame 原值 CGFloat → JSON number，**不**做 normalized [0..1]） | v0.3 C5 selector resolver 几何计算（near/below/above/leftOf/rightOf 阈值）用 logical points 更直观（"距离 < 16pt"）；normalized 需要 host TS 反查 device 分辨率，多一层间接。Settings cell on iPhone 17 Pro `frame=(0, 100, 402, 44)` 即整数 logical points（决策日志 C4 finding "General cell y≈0.48"是 normalized 旧表达，C1 起用 absolute；不冲突——C4 host-hid tap 仍接 normalized 接口，**transport 单位 vs selector 单位独立**）|
| **5** | **visible 怎么判** | **frame.intersects(appFrame) && !frame.isEmpty** —— **不**调 live `isHittable` | XCUIElementSnapshot 是 dead snapshot，**无** `isHittable` / `visible` 属性。可选路径：(a) 在 closure 内为每个 element 同步取 live `XCUIElement` 验 isHittable —— **拒绝**：live 查询 ~10ms/element × 100 节点 = 1s+ 阻塞 server，C1 不接受；(b) frame 启发式 —— **选**：snapshot.frame 与 app.frame 相交即 visible（粗但 cheap，~µs/节点）。**hasFocus / selected** 同理：snapshot 无 hasFocus 属性 → C1 占位 `false`；selected 有 isSelected 属性 → 真填。C2/C3 AX 主路径（`AccessibilityPlatformTranslation`）补 hasFocus 真值 |

## `XCUIElementSnapshotConverter` 伪代码（Swift 侧，UITest target 内）

> 位置：`swift-bridge/SimxRunnerUITests/SimxRunnerUITests.swift` 内 file-private function。**不**抽独立文件（C1 唯一消费者）。

```swift
// In SimxRunnerUITests.swift — file-private, single consumer.
// Bridge XCUIElementSnapshot (XCUI / XCTest type) → A11ySnapshotData POCO
// (SimxRunnerCore type, no XCUI dependency). Maintains the invariant that
// SimxRunnerCore library never imports XCTest/XCUI.

private func convertSnapshot(_ s: XCUIElementSnapshot) -> TreeRoute.A11ySnapshotData {
  // value is Any?; only String? subset is captured in C1.
  // Future checkpoints may extend to Bool / Int / Float when AX paths reveal them.
  let valueStr: String? = (s.value as? String).flatMap { $0.isEmpty ? nil : $0 }

  let kids = s.children.map { convertSnapshot($0) }

  return TreeRoute.A11ySnapshotData(
    elementTypeRawValue: UInt(s.elementType.rawValue),  // XCUIElement.ElementType.RawValue == UInt
    identifier:           s.identifier,                  // String, may be ""
    label:                s.label,                       // String, may be ""
    value:                valueStr,
    frame:                s.frame,                       // CGRect, logical points @1x
    isEnabled:            s.isEnabled,                   // Bool, public on snapshot
    isSelected:           s.isSelected,                  // Bool, public on snapshot
    children:             kids
  )
}

// And the SimxRunnerCore-side serializer (in TreeRoute.swift):

extension TreeRoute {
  static func serialize(
    _ root: A11ySnapshotData,
    appFrame: CGRect,
    logSink: ((String) -> Void)?
  ) -> Data {
    var truncated = false
    let dict = nodeToDict(root, appFrame: appFrame, depth: 0, truncated: &truncated, logSink: logSink)
    if truncated { logSink?("tree: truncated at depth \(MAX_DEPTH)") }
    return try! JSONSerialization.data(withJSONObject: dict, options: [])
  }

  private static func nodeToDict(
    _ d: A11ySnapshotData,
    appFrame: CGRect,
    depth: Int,
    truncated: inout Bool,
    logSink: ((String) -> Void)?
  ) -> [String: Any] {
    var out: [String: Any] = [:]
    out["rawType"]  = elementTypeName(d.elementTypeRawValue)
    if !d.identifier.isEmpty { out["identifier"] = d.identifier }
    if !d.label.isEmpty       { out["label"]      = d.label }
    if let v = d.value, !v.isEmpty { out["value"] = v }
    out["bounds"]   = ["x": d.frame.origin.x, "y": d.frame.origin.y,
                       "w": d.frame.size.width, "h": d.frame.size.height]
    out["enabled"]  = d.isEnabled
    out["selected"] = d.isSelected
    out["hasFocus"] = false          // C1 placeholder; AX 主路径 C2-C3 真填
    out["visible"]  = isVisible(d.frame, appFrame: appFrame)

    if depth >= MAX_DEPTH {
      truncated = true
      out["children"] = [[String: Any]]()
    } else {
      out["children"] = d.children.map {
        nodeToDict($0, appFrame: appFrame, depth: depth + 1, truncated: &truncated, logSink: logSink)
      }
    }
    return out
  }

  private static func isVisible(_ frame: CGRect, appFrame: CGRect) -> Bool {
    guard !frame.isEmpty else { return false }
    let inter = frame.intersection(appFrame)
    return !inter.isNull && !inter.isEmpty
  }

  static func elementTypeName(_ rawValue: UInt) -> String {
    switch rawValue {
    case 0:  return "any"
    case 1:  return "other"
    case 2:  return "application"
    case 3:  return "group"
    case 4:  return "window"
    case 9:  return "button"
    case 10: return "radioButton"
    case 12: return "checkBox"
    case 17: return "toolbarButton"
    case 21: return "navigationBar"
    case 22: return "tabBar"
    case 24: return "toolbar"
    case 26: return "table"
    case 32: return "collectionView"
    case 37: return "segmentedControl"
    case 40: return "switch"
    case 41: return "toggle"
    case 42: return "link"
    case 43: return "image"
    case 45: return "searchField"
    case 46: return "scrollView"
    case 48: return "staticText"
    case 49: return "textField"
    case 50: return "secureTextField"
    case 52: return "textView"
    case 53: return "menu"
    case 54: return "menuItem"
    case 58: return "webView"
    case 75: return "cell"
    // ... 完整 50+ 条目镜像 src/core/role.ts:43-104；unknown → "other"
    default: return "other"
    }
  }
}
```
