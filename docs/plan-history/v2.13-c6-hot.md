# plan-hot — v2.13 到 C6：护栏跟着 plugin 走到用户机器上

## 目标 checkpoint

C6：`sim-guard` 与 `adb-guard` 成为 plugin 的组成部分，装了 plugin 的人自动获得
「不许用 `booted` / 不许 `<verb> all` / 不许按名字寻址 / Android 不许不钉序列号」这几道拦截；
**本仓自己也用同一份**（不留两份副本各自漂移）；拒绝话术给出 smix 等价物，
否则 agent 只会换个写法重试。

## 前置条件

```bash
ls scripts/dev/{sim,adb}-guard.sh scripts/dev/hook-command.py
bash scripts/dev/sim-guard.test.sh && bash scripts/dev/adb-guard.test.sh   # 现状全绿
grep -n "sim-guard\|adb-guard" .claude/settings.json
```

## 步骤（线性，3 步）

### S1. 归位：一份实现，两个消费方

**红（写测试）**
- 文件：`scripts/dev/plugin-structure.test.py`（扩充）
- 断言：
  - `plugin/scripts/` 下有 `sim-guard.sh` / `adb-guard.sh` / `hook-command.py` 且可执行
  - `scripts/dev/` 下**不再有**同名副本（两份必然漂移，而漂移的那份正好是没人跑测试的那份）
  - 本仓 `.claude/settings.json` 指向 `plugin/scripts/`，即**我们自己用的就是发出去的那份**

**绿（实现）**
- `git mv` 三个脚本到 `plugin/scripts/`；`.claude/settings.json` 改路径；
  两个既有测试改引用路径，**断言本身一字不改**（搬迁若改了行为，它们就是发现处）

**重构**
- 无

### S2. 接进 plugin 的 PreToolUse，并让拒绝话术给出出路

**红（写测试）**
- 文件：`scripts/dev/plugin-structure.test.py`（再扩充）+ 两个 guard 测试各加一条
- 断言：
  - `plugin/hooks/hooks.json` 的 PreToolUse 匹配 `Bash`，命令用 `${CLAUDE_PLUGIN_ROOT}`
  - 每条拒绝话术里**至少出现一个可敲的 smix 命令**（`smix sim list` / `smix_devices` / `smix sim exec` 之一）
    —— 只说「不许」的护栏会被绕过，不会被遵守

**绿（实现）**
- hooks.json 加 PreToolUse；补齐话术里缺 smix 出路的分支

**重构**
- 无

### S3. 真会话里确实拦得住

**红（写测试）**
- 文件：`scripts/dev/v2.13-c6-guard-e2e.sh`
- 断言（真 `claude --plugin-dir` 会话）：
  1. 要求它跑一条 `xcrun simctl shutdown all` → 该命令**没有执行**，
     且会话里出现拒绝理由(用一台真 sim 的开机状态做旁证：跑完仍是 Booted)
  2. 要求它跑一条读操作 `xcrun simctl list devices -j` → 正常通过（护栏不误伤只读）
  3. 无 plugin 时同一条 shutdown 会被执行 —— **不做**：那要真关掉用户的 sim，
     改为断言 hook 脚本自身对该命令 exit 2（S1 的表驱动测试已覆盖）

**绿（实现）**
- 按需修正直到两条都过

**重构**
- 无
