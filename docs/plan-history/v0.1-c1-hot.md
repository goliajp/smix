## 步骤（线性，无分叉；1 个 step）

### S1. 装 vitest + 写 sanity test + 配 package.json scripts

**红（写测试）**
- 文件：`src/__tests__/sanity.test.ts`
- 断言：
  - `import { ExpectationFailure } from '../core/index.js'` 不抛
  - `new ExpectationFailure({ code: 'DRIVER_ERROR', message: 'test' }).toPrompt()` 返回的字符串含 `FAIL [DRIVER_ERROR]: test`
  - `describeSelector({ text: 'Sign in' })` 返回 `'{ text="Sign in" }'`
- 跑：`bun x vitest run`
- 期望：**exit 非 0**（因为 vitest 尚未安装；这是预期的红）

**绿（实现）**
- 文件 1：`package.json` —— 加 scripts: `"test": "vitest run"`, `"test:watch": "vitest"`
- 文件 2：`vitest.config.ts`（项目根）:
  ```ts
  import { defineConfig } from 'vitest/config'
  export default defineConfig({
    test: {
      include: ['src/**/*.test.ts'],
      exclude: ['**/node_modules/**', 'dist/**', '**/integration/**'],
      reporters: ['default'],
    },
  })
  ```
  - `**/integration/**` 排除以便集成测试单独跑（v0.1 后续 checkpoint 用）
- 跑：
  ```bash
  bun add -d vitest@^2.1.0
  bun run test
  ```
- 期望：**exit 0**，输出含 `1 passed`

**重构**
- 无（一个 step 不引入额外抽象）
