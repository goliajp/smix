# plan-cold/v2.md — v2.0.0 正式发布：超越 maestro + 全 parity + 最佳代码状态

## 为什么要做

v1.0.x 是单一 in-house consumer（insight）驱动的 27 版 dogfood cascade，代码内部化严重（26/28 crate 带开发噪声、注释混语言、一处 CJK 进了 shipped MCP schema、parser 与 VERB_TABLE 漂移、宪法自我违反四层契约）。v2 是第一个对外正式版：不做的话 smix 无法作为可信的公开工具进入 AI app dev/debug 闭环。

## 入口条件

- 设计 dossier 完成并经源码 audit（`.claude/design/v2.0/`，本 cycle 已完成）。
- `docs/v2.md` 版本边界 + 决策日志就位。
- workspace 无 in-house consumer 活动 batch 时才动源码：`pgrep -fl "runner.ts|smix run|supervise|bun test:e2e"` 为空（memory: runner-ops-check-batch-owner-first）。
- 动 Android/gradle/emulator 前查 `pgrep -fl "gradle|mobilegate|emulator"`（kevy 可能占用；memory: e2e-check-user-repo-active-build）。

## 资源依赖

- 环境：Xcode + iOS 26.5 runtime、Android SDK + emulator（C5）、本地 `claude` CLI（C2 AI-tier 测试用 mock）。
- 工具：`cargo-semver-checks`（C8 门禁）、`cargo test`、`swift test`、android-runner gradle。
- Agent：hygiene sweep（C1，26 crate + swift-bridge 344 CJK 行）量大，派 worktree-isolated agent 批量并行。

## 已知风险

- **hygiene sweep 误伤**：机械删注释可能删掉真 WHY 注释（OS-bug workaround / invariant）。对策：规则化——只删 vX.Y cN / Phase X / insight / round-N / Ask N / CJK-fragment / plan refs；保留 OS-bug / invariant / ABI 注释；每 crate diff review。
- **VERB_TABLE 对齐引出隐藏 verb**：parser 接受但缺失的 verb 精确集未知。对策：先写枚举测试暴露全集，再逐个注册/决策，不猜。
- **C5 Android 与 kevy gradle 抢资源**：对策：C5 真机 e2e 让位活动 batch，先做纯代码 + 单元。
- **wire v2 协商破坏旧 runner**：对策：握手失败 loud + upgrade hint，不静默 decode error。

## TDD 要点

correctness 类（VERB_TABLE gate / AI verdict / idle timing / codemod rule）走红绿：先写暴露问题的失败测试，再实现。hygiene sweep 类走「build 保持 zero-warning + 全测试绿」不变式，不是红绿。每 checkpoint 末尾机器可判验收命令。
