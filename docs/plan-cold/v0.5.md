# plan-cold/v0.5 — CLI repl + doctor 完整版

## 为什么要做
v0.4 后 SDK 完整可用，但 CLI 只有 `list` / `run`。TDD 场景的核心交互（"一步一停"）依赖 `simx repl`。同时 `simx doctor` 在 v0.1 是占位，需要补成真探测（Xcode / runtimes / 私有符号 / claude CLI / driver 健康）。

## 入口条件
```bash
test -f docs/plan-history/v0.4-c8-hot.md
# v0.4 端到端 AI 自修正 dogfood 通过
ls .simx/trace/wrong/failure.json 2>/dev/null || echo "需要先跑过 v0.4 e2e"
```

## 资源依赖
- 环境：与 v0.4 同
- CLI 框架：v0.1 已选定（citty 或 commander，看 v0.1 实际落地）
- REPL：node 内置 `readline` 或 `node:repl`；不引入 inquirer 等重型依赖
- 人 / agent：主对话

## 已知风险
- **`.save as <name>` 的代码生成要避免行尾差异**：用 prettier 嵌入或自家小 formatter
- **REPL 历史 selector 推断**：录下来的 trace 是元素 bounds + role + name，要还原成 Playwright 风格 selector，可能歧义。优先 id > role+name > text
- **driver 在 REPL 中长跑可能僵尸化**：每 50 命令 ping 健康；触发 v0.7 的稳定性问题，但 v0.5 先用简单 ping

## TDD 要点
- CLI 测试：child_process spawn CLI，断言 stdout/exit code
- REPL 测试：写 stdin 给 child，断言 stdout
- `.save` 测试：固定 trace fixture → 断言生成的 TS 文件可被 `tsc --noEmit` 校验
- `doctor` 测试：mock 各探测函数，断言输出 schema

## Checkpoint 概要列表
- **C1** `simx repl` 启动 + 一行调用 + 每步自动打印 screen_describe 摘要（top 5 元素）
- **C2** REPL 命令历史 + 撤销（`.undo`）+ 重做（`.redo`）
- **C3** REPL `.save as <name>` 生成 TS 文件：selector 推断（id > role+name > text）+ tsc 校验
- **C4** `simx doctor` 完整版：Xcode 版本 / runtimes 列表 / 9-arg Indigo 符号 / `AccessibilityPlatformTranslation` 符号 / claude CLI 是否可用 + 已登录
- **C5** `simx run` 增强：`--device` / `--grep` / `--json` / `--bail` 全部生效
- **C6** `simx boot <device>` 单独命令（懒等 boot 完成）

## 出口验收
```bash
bun run test
bun src/cli/index.ts doctor --json | jq '.checks | length'  # 期望：≥5
echo -e "launch com.apple.calculator\ntap text=2\n.save as calc-two\n.exit" | \
  bun src/cli/index.ts repl --device 'iPhone 16 Pro'
# 期望：生成 examples/calc-two.test.ts，bun x tsc 检查通过
bun src/cli/index.ts run examples/calc-two.test.ts --json | jq '.passed'  # 期望：1
```
