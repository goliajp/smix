# plan-cold/v0.4 — SDK 行为完备 + Trace 输出

## 为什么要做
v0.3 后所有 selector 能 resolve，但失败信息还是 stub（`visibleElements: []` / `screenshot: undefined`）。v0.4 把 v0 设计的"AI-readable 错误"真正实现——失败瞬间抓屏 + dump 元素 + edit-distance 算建议，写 `.simx/trace/`。完成后 v1 Success Criteria #2（一次自我修正）才可能达成。

## 入口条件
```bash
test -f docs/plan-history/v0.3-c7-hot.md
bun src/cli/index.ts run examples/login.test.ts  # v0.3 e2e 通
# matcher 失败路径目前应该是 visibleElements 为空（未填充）
# 这是 v0.4 要打掉的状态
```

## 资源依赖
- 环境：与 v0.3 同
- 文档：无新增。本阶段完全在 TS 侧
- 人 / agent：主对话即可，不需要 sub-agent

## 已知风险
- **失败瞬间抓屏可能影响后续状态**：截图本身无副作用，但是 `driver.describe()` 不能等太久（matcher 已经在失败 path）。timeout 设 1s
- **edit-distance 在大量元素时慢**：限 top 50 visible 元素再算
- **trace 文件爆磁盘**：默认每 case 上限 50 截图，超过覆盖最早；提供 `--trace=off` 关掉
- **绝对路径 vs 相对**：trace 写 `<cwd>/.simx/trace/`，CI 上 cwd 不同要兼容

## TDD 要点
- 全 TS 单测，无需 driver / sim
- mock driver.describe 返回固定 `ScreenDescription`，断言 matcher 失败时 `ExpectationFailure` 字段被填
- 断言 `toPrompt()` 输出字符串包含 visibleElements 列表
- e2e：故意写一个错的 selector，跑测试，检查 `.simx/trace/<case>/failure.json` 内容
- 用 Claude CLI dogfood：把 `failure.json` 喂给 `claude -p`，断言它能给出正确修正（人工抽检 3 个 case）

## Checkpoint 概要列表
- **C1** matcher 失败时 `visibleElements` 真填充（调 `driver.describe()`）
- **C2** matcher 失败时 `screenshot` 真嵌入 base64 + 写 PNG 到 trace 目录
- **C3** `suggestions` edit-distance 算法接通（已有原型在 matchers.ts）
- **C4** `.simx/trace/<case>/steps.jsonl`：每个 action 一行 JSON
- **C5** `.simx/trace/<case>/<step>.png`：每个 action 后自动截屏
- **C6** `.simx/trace/<case>/failure.json`：失败时序列化 `ExpectationFailure`
- **C7** `waitFor` / matcher auto-poll 真实生效（50ms → 500ms 指数退避到 timeout）
- **C8** Dogfood checkpoint：3 个故意错的 selector 案例，每个 `failure.json` 喂给 `claude -p` 都能 0-shot 修对

## 出口验收
```bash
bun run test
# 故意错的测试
cat > /tmp/wrong.test.ts <<'EOF'
import { test, expect } from '../../src/sdk/index.js'
test('wrong', async ({ app }) => {
  await app.launch('com.apple.calculator')
  await expect(app.element({ text: 'Sgin in' })).toBeVisible()
})
EOF
bun src/cli/index.ts run /tmp/wrong.test.ts || true
# 期望：exit 1，stdout 含 toPrompt() 输出，`.simx/trace/wrong/failure.json` 存在且 visibleElements 非空
claude -p "Fix the selector based on this failure: $(cat .simx/trace/wrong/failure.json)" --output-format text

```
