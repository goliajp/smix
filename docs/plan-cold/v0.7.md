# plan-cold/v0.7 — Hardening + 验收

## 为什么要做
v0.6 后功能闭环完成，但 v1 success criteria 还差三条：[5] 100 case 长跑不僵尸化、[6] iOS 17.5/18.4/26.x 三 runtime 全过、[7] Claude Code plugin 一键集成。v0.7 是 hardening：补稳定性、补 CI 矩阵、补分发清单。完成即 v1.0。

## 入口条件
```bash
test -f docs/plan-history/v0.6-c8-hot.md
bun scripts/mcp-smoke.ts > /dev/null && echo ok  # v0.6 e2e
```

## 资源依赖
- 环境：与 v0.6 同
- CI：GitHub Actions macOS-15 runner（需要 Xcode 26 镜像；如果尚未 GA 用 macos-15-arm64 self-hosted）
- 多 runtime：本机或 CI 上安装 iOS 17.5 / 18.4 / 26.x simulator runtime
- Claude Code plugin：[Claude Code plugin 文档](https://claude.com/code)（具体路径热化时查最新）
- 人 / agent：主对话；CI 配置可考虑 sub-agent 隔离

## 已知风险
- **iOS 17.5 / 18.4 runtime 在 CI 上未必预装**：用 `xcversion simulators --install` 或预 cache
- **长跑测试本身耗时**：100 case smoke 大概 5-10 分钟，CI 上要单独 job
- **Claude Code plugin manifest schema 不稳**：热化时实测，可能需要联系 Anthropic 拿当时最新
- **GHA Xcode 26 镜像**：在文档生成时（2026-05）应已 GA，但要二次确认

## TDD 要点
- 长跑稳定性：起一个 e2e 测试跑 100 个简单 case（每个 launch + tap + assert），断言 driver 不僵尸化、所有都过
- runtime 矩阵：CI matrix strategy 跑同一套 smoke 在 3 个 runtime 上
- plugin manifest 测试：用 `claude` CLI 加载 manifest 后 `tools/list` 应该返回 simx 的 18 个 tool

## Checkpoint 概要列表
- **C1** 长跑稳定：100 case 串行不僵尸化（自动每 50 case 重启 XCUITest runner + health ping）
- **C2** 自动化 100-case 套件 + CI workflow 跑通（GitHub Actions macos-15）
- **C3** runtime 矩阵：CI matrix iOS 17.5 / 18.4 / 26.x，每条都跑 smoke 全过
- **C4** `simx doctor --json` 把每个 check 的版本兼容性输出（结构化 schema 固化）
- **C5** Claude Code plugin manifest（`claude-plugin.json` 或同名）+ 安装说明，能通过 `claude /install simx` 装上
- **C6** v1.0 自动化验收脚本：跑遍 v1.md "Success Criteria" 7 条，全部输出 ok
- **C7** README / docs/ 更新到 v1.0 发布状态
