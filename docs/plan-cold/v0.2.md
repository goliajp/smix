# plan-cold/v0.2 — HID 注入层

## 为什么要做
v0.1 后 SDK 能 launch/screenshot 但不能交互。HID 注入层让 `tap/doubleTap/longPress/swipe/fill` 真正生效，且具备 iOS 17/18/26 三 ABI 适配 + XCUITest 公开 API 兜底。这是延迟红利（ms vs 数十 ms）的来源，决定 simx 的"快"卖点能否兑现。

## 入口条件
```bash
test -f docs/plan-history/v0.1-c7-hot.md           # v0.1 完成
bun run test                                     # v0.1 测试全过
bun src/cli/index.ts run examples/screenshot-only.test.ts  # 端到端通
xcrun simctl list runtimes -j | jq -r '.runtimes[].version'    # 含 26.x（至少一个 17+）
```

## 资源依赖
- 环境：Xcode 26+、iOS 26 runtime 必须有（否则 9-arg Indigo 无法验证）
- Swift toolchain：Xcode 自带
- 私有符号参考：`SimulatorKit.framework`、`CoreSimulator.framework`、`IOKit`
- 外部参考：
  - [tddworks/baguette](https://github.com/tddworks/baguette) — iOS 26 9-arg Indigo 实战
  - [Maestro re-building iOS driver](https://maestro.dev/blog/maestro-re-building-the-ios-driver) — XCUITest 兜底架构
- 人 / agent：Swift bridge 由专门 sub-agent 在 worktree 中开发更稳

## 已知风险
- **私有符号在 Xcode 大版本 break**：全部 `dlsym` 动态加载；`simx doctor` 检测；break 时主路径降级 XCUITest tap
- **9-arg Indigo 文档稀缺**：参考 baguette 的逆向；自家加 fuzz test，捕获 IOHIDEvent 树构造错误
- **XCUITest 兜底要起 runner**：runner 是一个永不结束的 XCTestCase，包 FlyingFox。CI 上启动慢 → 复用单一 boot 的 sim
- **typeText iOS 15+ 慢**：长文本一律走 `UIPasteboard` 注入 + 触发粘贴；启动时 `defaults write com.apple.iphonesimulator ConnectHardwareKeyboard 0`

## TDD 要点
- Swift 侧用 XCTest 写 HID 单测：构造 IOHIDEvent → 断言写入到正确 mach port
- TS 侧 mock Swift bridge stdio，断言协议
- 集成测试：真实模拟器上 `tap` 一个已知坐标的 button，断言 `accessibilityActivated` 触发
- 用 Apple 的 Calculator app 做基准 e2e（不需要构建 app）

## Checkpoint 概要列表
- **C1** XCUITest runner 起得来（FlyingFox HTTP server 在 sim 内 listen），`/health` 200
- **C2** XCUITest tap/typeText fallback 通：通过 runner 点 Calculator 按钮成功
- **C3** 5-arg Indigo HID 跑通（iOS 17/18 路径）：写入 mach port，Calculator 响应
- **C4** 9-arg Indigo HID + IOHIDEvent 树跑通（iOS 26 路径），含多指触摸
- **C5** `InputChannel` 抽象 + version dispatch；`simx doctor` 报告每条路径可用性
- **C6** SDK `tap/doubleTap/longPress/swipe/fill` 接通 InputChannel；`fill` 长短文本分流
- **C7** `examples/login.test.ts` 的 tap/fill 部分跑通（selector 部分还在 v0.3）
