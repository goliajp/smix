# simx v1 — 功能边界（已锁定）

> **v1 = 第一个能让 AI 0-shot 写测试、一次自我修正、跑通完整闭环的版本。**
> 不是功能完备版。v0 是 types-only 骨架；v1 = MVP 落地。

## 1. 产品定位（锁定）

**Claude Code 订阅用户的 iOS Simulator 伴侣**。

不做 multi-provider VLM 抽象，不管 API key，不做真机。所有 AI 路径走本机 `claude` CLI；分发优先做 Claude Code MCP 一键集成。

## 2. 必须包含（5 个模块）

### A. Swift Bridge（Driver 真实现）

| 能力 | 主路径 | 兜底 |
|---|---|---|
| Sim 控制（list/boot/install/launch/terminate/screenshot/permissions/appearance/locale/network） | CoreSimulator framework 直连 | `simctl` shellout |
| HID 注入 iOS 17/18 | 5-arg Indigo `IndigoHIDMessageForMouseNSEvent` | XCUITest `tap()` |
| HID 注入 iOS 26+ | **9-arg Indigo**, digitizer target `0x32` | XCUITest `tap()` |
| AX 读取 | host-side `AccessibilityPlatformTranslation` | XCUITest `XCUIElementSnapshot` via runner |
| 文本输入 | HID 键盘（短）+ `UIPasteboard` 粘贴（长） | XCUITest `typeText()` |

所有私有符号 **dlsym 动态加载**，不硬链接。`simx doctor` 报告每条路径可用性。

### B. SDK 行为完备

- Selector resolver：4 base + 8 modifiers 全部生效（geometry 计算在 Swift 侧）
- Matcher 失败上下文真填充：`visibleElements` / `screenshot` / `suggestions`（edit-distance）
- **Cell 抽象 L1+L2**：`acquireCell` API + 每 Cell 独立 runner port（22087+index）+ 独立 `.simx/cells/<id>/` trace dir + Driver 接受 `Cell` 而非裸 `SimSession`。v1 单 Cell 跑，**API 必须 cell-aware**（避免 v1.1 retrofit）。详 `design.md §Cell 模式`
- Trace 输出：`.simx/cells/<id>/trace/<case>/{steps.jsonl, *.png, failure.json}`
- `waitFor` / 自动 poll 真生效

### C. CLI（5 子命令 + 1 工具命令）

```
simx list                          列模拟器
simx boot <device>                 启动模拟器
simx run <files...>                串行跑测试，失败打印 ExpectationFailure.toPrompt()
simx repl [--device=...]           交互式；.save as <name> 转 TS 文件
simx mcp                           起 stdio MCP server
simx doctor                        检测 Xcode / runtime / 私有符号 / claude CLI 可用性
```

### D. MCP Server（18 工具）

stdio 协议 + **Claude Code plugin 形态分发**。`screen_describe` 一等公民；所有交互 tool 默认返回新屏幕 summary（省 round-trip）。

`explain_screen` **默认开启**，子进程调本机 `claude -p ... --image ...`。`claude` 不可用时 tool 返回明确错误指向 Claude Code 安装。

不包含 `recording_start` / `recording_stop` —— v1 用 `simx repl` 的 `.save` 替代。

### E. 工程基础

- CI：GitHub Actions macOS-15，runtime 矩阵 iOS 17.5 / 18.4 / 26.x
- 单元测试：vitest，core/ 全覆盖；matchers 用 mock driver；Swift bridge 用 XCTest
- 集成测试：标 `@integration`，依赖真 simctl
- E2E：标 `@e2e`，CLI 端到端
- 错误码：`FailureCode` 表完整，每个 code 配修复指引文档
- 日志：structured JSON 写 `.simx/logs/`

## 4. Success Criteria（验收线）

```
[1] AI 0-shot：Claude Code 拿 README "Authoring guide" + MCP server，0-shot 写出
    跑通的 examples/login.test.ts 等价测试
[2] 一次自我修正：失败时把 ExpectationFailure.toPrompt() 输出 feed 回 AI，
    一次内能修对 selector
[3] 冷启动延迟：simx run 到首 tap 完成 < 5s
[4] 单 tap 延迟（iOS 26 主路径）< 50ms
[5] 长跑：100 case 串行连续跑不僵尸化、不漏 element
[6] 兼容：iOS 17.5 / 18.4 / 26.x 全部通过冒烟集
[7] Claude Code 集成：claude /install simx 一键启用 MCP
```

## 5. 关键技术风险与对策

| 风险 | 对策 |
|---|---|
| iOS 26 9-arg Indigo ABI 私有，Xcode 大版本可能 break | dlsym 动态加载；`simx doctor` 检测；break 时降级 XCUITest |
| testmanagerd 长跑僵尸化 | 每 50 case 自动重启 runner；health ping |
| `typeText` iOS 15+ 慢 | 短 HID / 长 pasteboard；启动时禁硬件键盘 |
| `XCUIElementSnapshot` 60 层深度限制 | flatten + 分屏 snapshot；文档建议 RN 加 a11y identifier |
| `AccessibilityPlatformTranslation` 私有 | 同 Indigo 对策 |
| 模拟器在 CI 启动慢 | 预 boot pool；run 默认复用已 boot 实例 |
