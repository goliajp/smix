# Examples

Real, runnable AI-authored test samples. Each one is a single `.test.ts` file in [`examples/`](https://github.com/goliajp/smix/tree/develop/examples) on GitHub — what an AI should produce when handed the [Authoring guide](/docs/authoring) and an `iOS simulator + smix`.

- [login-tap: selector showcase](/docs/examples-login-tap) — 4-base + modifier selectors driving real Settings UI.
- [tap-text-selector: minimal smoke](/docs/examples-tap-text-selector) — single `app.tap({text})` against an auto-launched Preferences root.
- [screenshot-only: v0.1 baseline](/docs/examples-screenshot-only) — sim boot + `app.launch` + `app.screenshot()` with PNG magic-byte verification.

> Source: [examples/ on GitHub](https://github.com/goliajp/smix/tree/develop/examples)
