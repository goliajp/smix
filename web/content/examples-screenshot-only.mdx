# screenshot-only

v0.1 milestone. No HID, no runner — just sim boot + `app.launch` + `app.screenshot()` returning real PNG bytes.

```ts
import { test } from '../src/sdk/index.js'

test('screenshot only', async ({ app }) => {
  await app.launch('com.apple.mobilesafari')
  const png = await app.screenshot()
  if (png.length < 1000) {
    throw new Error(`screenshot too small: ${png.length} bytes`)
  }
  if (!(png[0] === 0x89 && png[1] === 0x50 && png[2] === 0x4e && png[3] === 0x47)) {
    throw new Error('screenshot missing PNG magic bytes')
  }
})
```

## Reading guide

**PNG magic-byte check.** `0x89 0x50 0x4e 0x47` is the canonical 4-byte PNG header (`\x89PNG`). The assertion proves the screenshot returned by `app.screenshot()` is a real PNG payload, not an empty buffer or HTML error page.

**No runner needed for v0.1.** This example predates the XCUITest SmixRunner: it only exercises `simctl boot` + `simctl io screenshot`, the v0.1 baseline path. Once HID and AX-tree ingress land in v0.2, the same shape extends to richer assertions; the screenshot path stays unchanged.
