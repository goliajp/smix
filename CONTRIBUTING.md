# Contributions

`smix` is developed as a closed project. **Upstream does not accept external contributions.**

Specifically:

- **Pull requests** — will not be reviewed or merged.
- **Feature requests** — will not be tracked.
- **Bug reports** — issues on this repository are not monitored.
- **Support questions** — no support channel is provided.

The source is published under the dual Apache 2.0 / MIT license so you are free to fork the project, adapt it to your own needs, and redistribute your fork per those license terms. If you build something interesting on top of `smix`, you are welcome to publish it under your own name; you do not need to attribute it to this repository beyond what the license requires.

## Why closed development

Maintaining a public feedback loop imposes engineering and coordination overhead that is incompatible with the release cadence and quality bar this project targets. Keeping the surface closed lets us hold the wire format, ABI, and CLI stable within a major-version series without negotiating with a broader community.

## If you find a security issue

The project does not publish a security-report channel. If you fork the code and discover a vulnerability that also affects a version you have redistributed, please treat it as a defect in your own fork; you are of course free to publish an advisory under your fork.

## Using the code

The Apache 2.0 / MIT dual license grants you every practical freedom to use, modify, and redistribute the source. No further permission is required from the authors.
