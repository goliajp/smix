# smix-sdk

smix-sdk — user-facing public surface for the smix Rust library.
Provides `App` plus ergonomic selector helpers and matchers, wrapping
`SimctlDriver` + `SimctlClient` + `HttpRunnerClient`.

Part of the [smix](https://github.com/goliajp/smix) workspace. See the
top-level [README.md](../../README.md) for the project overview.
